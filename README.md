# PhotoStudio Portfolio

Ce projet est la réalisation d'un site web statique pour un photographe amateur, "PhotoStudio", selon le cahier des charges fourni.

## Structure du projet
- `index.html` : Page d'accueil avec hero section, services et galerie.
- `portfolio.html` : Page des réalisations avec filtres CSS purs et grille d'images.
- `contact.html` : Page de contact avec formulaire et carte Google Maps.
- `css/style.css` : Fichier de styles CSS principal avec variables CSS, flexbox/grid, et responsive design.
- `js/script.js` : (Bonus) Petit script pour le menu hamburger et autres interactions.
- `images/` : Dossier contenant les images du site.

## Technologies utilisées
- HTML5
- CSS3 (Variables, Flexbox, Grid, Animations)
- Google Fonts (Poppins, Open Sans)
- FontAwesome / SVG Icons
- JavaScript (pour le menu mobile)

## Fonctionnalités
- Design responsive (Mobile-first, 2 breakpoints minimum)
- Thème dans les tons bleus
- Filtres de portfolio en CSS pur
- Animations au survol des cartes et boutons
- Code validé W3C

## Déploiement
Le site peut être déployé sur n'importe quel serveur web statique (GitHub Pages, Netlify, Vercel, etc.).
